Store genuine BrandGuard screenshots in this folder and reference them from the root README.

| Filename | Capture |

| 01-content-review.png | Content list and review status |
| 02-finding-details.png | A finding with its source quote, severity, confidence, and suggested diff |

## Capture checklist

- Use the synthetic Brewline Coffee demo workspace.
- Keep the browser viewport consistent across captures.
- Show enough context to explain each feature without exposing unnecessary personal data.
- Hide browser password managers, API keys, email addresses, and local filesystem details.
- Prefer PNG captures at 1440 × 900 or a similarly readable desktop viewport.
- Do not redraw, fabricate, or materially alter application screenshots. Label any conceptual mockup as an illustration.

The architecture diagram in `../assets/brandguard-flow.svg` is a conceptual flow diagram, not a screenshot of the running application.
